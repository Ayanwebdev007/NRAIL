# UX-Audit Skill

This skill provides a framework for evaluating and refining the user interface to meet "Premium" and "Luxury" standards.

## Core Capabilities

1.  **Aesthetic Evaluation**:
    *   Review color palettes for harmony and sophistication (avoiding generic colors).
    *   Check for modern typography (Google Fonts like Inter, Outfit, etc.).
    *   Evaluate the use of gradients, glassmorphism, and subtle micro-animations.

2.  **Structural Audit**:
    *   Assess white space and "breathing room" (aiming for spacious, luxury layouts).
    *   Verify visual hierarchy: ensure the most important elements (CTAs, Headlines) pop.
    *   Check for consistent spacing and alignment across sections.

3.  **Accessibility & Contrast**:
    *   Verify text-to-background contrast ratios for readability.
    *   Check hit targets for buttons and interactive elements.

## When to Use

- After implementing a new section or page.
- When the user asks: "How does this look?" or "Make it feel more premium."
- Before a final delivery to ensure "pixel-perfect" quality.

## Workflow

1.  **Visual Scan**: Use the browser tool to view the page at different breakpoints.
2.  **Contrast Check**: Analyze colors against WCAG standards.
3.  **Premium Pass**: Apply the "Antigravity Premium Design" checklist (Gradients? Micro-animations? High-end fonts?).
4.  **Reporting**: Report specific, actionable improvements to the USER.
